                            Need to

                            What to download, and how to set up everything else: Google, Claude, your Claude apps, Telegram, your iPhone, TV, iPad, fitness band and second laptop, updates, Discover and reverse engineering.

                            Download
                            Nova downloads and turns on what every feature needs, by herself.

                                Everything runs on this PC once it's downloaded. Optional ones are only for the feature they name.

                                iPhone · Nova Lite
                                1. Click iPhone pairing code below (it turns PHONE on). If Windows asks about networks, allow Private networks.
                                2. Point the iPhone camera at the code and open the link. The phone and this PC must be on the same Wi-Fi.
                                3. Tap Download certificate → Allow. Then iPhone Settings → Profile Downloaded → Install, and General → About → Certificate Trust Settings → turn on Alfred Local CA (once).
                                4. Back on the page: Open Nova Lite → Share → Add to Home Screen.
                                5. Put it on a stand with its charger; Display & Brightness → Auto-Lock → Never. Hold to talk on it like here.
                                Google · Gmail, Calendar, Drive
                                1. Open console.cloud.google.com with your Google account → Select a project → New project (any name, e.g. Nova).
                                2. APIs & Services → Library: enable the Gmail API, the Google Calendar API and the Google Drive API.
                                3. APIs & Services → OAuth consent screen (Google Auth Platform): Get started, app name Nova, your email, audience External. Under Audience → Test users, add your own Gmail address.
                                4. Clients → Create client → type Desktop app → Create → Download JSON.
                                5. Save that file as %LOCALAPPDATA%\Alfred\google_client.json (create the Alfred folder if it isn't there).
                                6. Click Connect Google. In the browser, pick your account; on “Google hasn't verified this app” click Continue (it's your own app), and tick Gmail, Calendar and Drive.
                                7. Connected before Calendar or Drive came? Click Add Google Calendar / Add Google Drive in Settings → Connections to allow the new part.
                                8. Ask: “any new mail?”, “draft a reply to number 2”, “what's on Friday?”, “add dentist Friday at 3”, “find my budget in Drive”, “read file 1”. Mail is only ever drafted, never sent; Drive is read-only.
                                Claude · Nova's online brain

                                On your Claude plan (no API credit)

                                1. Install Claude Code: in PowerShell run irm https://claude.ai/install.ps1 | iex (or get it from claude.com/product/claude-code).
                                2. Open a new terminal, run claude once and sign in with your Claude account (Pro or Max). Close it with /exit.
                                3. In Settings → Nova's brain choose Claude (or Auto), and Pay with: My Claude plan. It counts toward your plan's usage limit; at the limit the AI on this PC answers.

                                Or with an API key

                                1. console.anthropic.com → API keys → Create key, and add a little credit under Billing.
                                2. Settings → Nova's brain → Pay with: An API key, paste it and click Save key. It stays on this PC.

                                Your claude.ai Gmail and Google Drive connectors

                                1. On claude.ai → Settings → Connectors, connect Gmail and Google Drive with the same Claude account Claude Code signed in with.
                                2. Settings → Nova's brain → tick Also let Claude use my claude.ai Gmail and Google Drive (plan only). Claude then reads, searches and drafts with them; Nova blocks sending, sharing and deleting.
                                Your Claude apps · Nova's Gmail and Drive

                                Give Claude Code and Claude Desktop on this PC Nova's Gmail and Google Drive tools (read mail, save drafts, search and read Drive) over MCP, through Nova's own Google sign-in. Only this PC can reach it, with a private key.

                                1. Connect Google first (the Google folder above).
                                2. Click Turn on below. Nova keeps serving it while it runs (keep Nova in the tray).
                                3. Claude Code: click Copy next to the Claude Code command, paste it in a terminal and press Enter. Check with claude mcp list: nova-google shows as connected.
                                4. Claude Desktop: needs Node.js (nodejs.org, LTS). In Claude Desktop: Settings → Developer → Edit Config, put the copied block's nova-google entry inside "mcpServers" (or paste the whole block into an empty file), save, and restart Claude Desktop.
                                5. Ask your Claude app “check my unread mail with nova-google” or “find my notes on X in Drive”. It asks you before each tool.
                                6. New key shuts out every app set up with the old one; paste the new setup into the apps you still use.

                                Telegram · Nova from anywhere
                                1. In Telegram, open @BotFather → /newbot, give it a name, and copy the token it sends (123456789:AA…).
                                2. Paste the token below and click Save token, then turn Telegram on.
                                3. Open your new bot in Telegram and send it the pairing code shown here. From then on it answers only you.
                                4. Text it or send a voice note from anywhere. Your PC has to be on and awake (Nova runs on it).

                                Even with the PC off (free Cloudflare relay)

                                1. Make a free account at dash.cloudflare.com (no card needed).
                                2. My Profile → API Tokens → Create Token → Edit Cloudflare Workers template → Continue → Create. Copy it.
                                3. Paste it below, choose who answers while the PC is off, and click Set up relay. Nova uses the token once and doesn't keep it.

                                TV
                                1. Turn PHONE on (the iPhone folder's first step does it).
                                2. Click Show the links, then open the TV address in the TV's web browser and bookmark it.
                                3. The TV shows a 4-digit code: click Allow on that code here. No browser on the TV? Mirror this PC instead (Win+K, Chromecast or HDMI).
                                4. Drag a reply (or a photo from Explorer) onto Drop here to show it on the TV, press → TV on a reply, or say “Hey Nova, put that on the TV”.

                                TV: open in the TV's browser, then click Allow on the code it shows.

                                iPad · control deck
                                1. Install Nova's certificate on the iPad first, as in the iPhone folder (step 3).
                                2. Click Show the deck code and scan it with the iPad camera, open it, then Share → Add to Home Screen.
                                3. Type on its keyboard: the letters go into the window in front on this PC. Type sends whole text in any language; the widgets show Nova, the time, the weather and your music.
                                Fitness band
                                1. Wear a band, watch or chest strap that shares heart rate over Bluetooth: Polar, Garmin (turn on Broadcast heart rate), Wahoo, Coros, many Amazfit and Xiaomi bands.
                                2. Turn Bluetooth on in Windows, then click Connect heart rate.
                                3. Ask “Hey Nova, how's my heart rate?”: live heart rate, average, lowest, highest and HRV.

                                Install and updates
                                1. Get Nova-Setup.exe from github.com/lekietphamanh-maker/NOVApersonalAI/releases/latest and run it. It installs for you only (no admin), with Start menu and desktop shortcuts. If SmartScreen warns, click More info → Run anyway.
                                2. Moving from a zip copy? Install the setup once; your settings, memory and models stay (they live in %LOCALAPPDATA%\Alfred).
                                3. Settings → Updates: tick Check for new versions…. Nova downloads new versions itself, checks their SHA-256 and waits for you to click Restart to update.
                                4. Something wrong after an update? Install the previous version rolls back.
                                Discover · GitHub picks
                                1. BRIEF → Your interests: add up to four (they're what Discover searches for).
                                2. Tasks → Discover → Tune Discover: your GitHub username (your repos and stars shape the picks).
                                3. Optional: a token only raises GitHub's rate limit. github.com/settings/personal-access-tokens → Generate new token, public repositories, no permissions; paste it and click Save.
                                4. Add on a pick has Claude Code (your plan) study it read-only at a pinned commit. If it suggests a skill, you read it and choose; nothing from GitHub is installed or run in Nova.
                                Reverse engineering · REA
                                1. Set up Claude Code (the Claude folder above).
                                2. Install Node.js 22.23 or newer (nodejs.org → LTS: run the downloaded .msi; the file alone isn't an install). Nova finds it without a restart.
                                3. Unzipped Node.js, or Nova still says it can't find it? Paste where node.exe is below (e.g. C:\Tools\node-v24\node.exe or its folder) and click Save.
                                4. Tasks → Reverse engineering → Turn on, and read what it does.
                                5. Say “reverse engineer <app, site, file or folder> and tell me how <part> works”. Only on things you're allowed to analyse. The report lands in outputs/ and the Library.
                                Direct app control · Office, OBS, VS Code
                                1. Word, Excel, PowerPoint: nothing to set up. Say “make a Word document from my notes on …”, “put these numbers in Excel with a bar chart”, “turn this into slides”. Nova makes the real file in Documents\Nova Documents and opens it.
                                2. OBS: in OBS, Tools → WebSocket Server Settings → Enable WebSocket server. If you keep Enable Authentication on, click Show Connect Info, copy the password and paste it below. Then: “start recording”, “switch to the Gaming scene”, “stop recording”. Going live asks you first.
                                3. VS Code: install it, then in VS Code press Ctrl+Shift+P → Shell Command: Install 'code' command in PATH (the installer usually does this). Then: “open my portfolio project in VS Code”.
                                4. Anything else still works the old way: Nova clicks on the screen with Screen assist.
                                Ollama Cloud · free online brain
                                1. Make a free account at ollama.com.
                                2. Settings → Nova's brain → choose Ollama Cloud, then click Sign in to Ollama and approve this PC in the browser.
                                3. Free use has session and weekly limits; past them the AI on this PC answers.
                                Second laptop

                                1. Install Nova on the other PC too. It checks that PC's processor, graphics and memory and offers the model that suits it.
                                2. Install Syncthing on both PCs (free, PC to PC, no cloud): SyncTrayzor (GermanCoding's version), or in a terminal winget install --id BillStewart.SyncthingWindowsSetup -e.
                                3. In Syncthing on this PC: Add Folder → the vault folder above, then Add Remote Device with the other PC's ID and share the folder with it. Accept it on the other PC, into a new empty folder.
                                4. On the other PC: Settings → Second brain → set that folder as the vault, then turn this on there too.

                                On the laptop, Nova uses the same brain choice and the same Library; paste your Claude key there too if Claude answers.
